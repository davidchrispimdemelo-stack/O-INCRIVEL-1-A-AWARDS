1ºA AWARDS 2026 — LEIA PRIMEIRO

1. Abra GUIA_COMPLETO.md e siga as partes na ordem. Ele explica tudo em detalhes.
2. Os arquivos private\roster.json (RAs) e private\recados_individuais.sql (mensagens) são privados; o SQL dos recados é baixado separadamente, não vem no ZIP do site. Nunca os coloque em docs nem os publique no GitHub.
3. Crie um projeto Supabase, execute supabase\schema.sql, configure os segredos e publique a função awards-api.
4. Execute py tools\import_roster.py uma única vez para importar a turma. Depois retire o segredo temporário ROSTER_SETUP_KEY. Em seguida, execute private\recados_individuais.sql no SQL Editor do Supabase e publique novamente a função awards-api.
5. Edite docs\config.js com a URL do projeto Supabase e a chave pública.
6. Publique somente a página pelo GitHub Pages, usando a pasta /docs.
7. Teste o login de ADM e confirme que tudo funciona. Só então comece a contagem de 20 dias.

CUIDADO: peça autorização à escola/responsável. O site do GitHub Pages é público. Nunca publique a lista privada, o SQL dos recados, senhas ou chaves secretas.

## Sistema de pontos por preferência

Em cada categoria, cada participante pode indicar até duas pessoas diferentes: a primeira opção vale **1 ponto** e a segunda vale **0,5 ponto**. É permitido votar apenas na primeira opção ou pular a categoria; não é permitido preencher apenas a segunda opção nem escolher a mesma pessoa nas duas posições. A classificação e os quatro finalistas são definidos pela soma dos pontos. Cédulas antigas, que só têm uma pessoa por categoria, continuam sendo lidas como primeira opção (1 ponto).
